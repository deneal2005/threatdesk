## 2. Architecture & Design Principles

1. **Non-Technical Usability:** Every signal, check result, and verdict is formatted in plain English. Words like "clean" or "safe" are never used; instead, ThreatDesk reports objective findings ("No strong signals", "Insufficient data", "High risk").
2. **Append-Only Evidence:** Every captured HTTP response, WHOIS/RDAP record, and app listing is saved with a SHA-256 hash in the `evidence` table, creating an immutable forensic audit trail.
3. **SSRF Guard:** All outbound network fetches go through strict IP validation (`threatdesk/safety.py`), blocking private, loopback, link-local, and cloud metadata IP ranges (169.254.169.254).
4. **Tenant Isolation:** Multi-organisation isolation enforced on every database query via `threatdesk/tenancy.py:scoped`.
